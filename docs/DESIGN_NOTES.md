## 数据与业务

| 项 | 决策 |
|---|---|
| 默认分类种子 | 新账本预置 32 个支出、17 个收入一级分类，保留既有种子 ID 和顺序；收入补充项含租金、分红、利息、补贴、奖学金、稿费、佣金、二手出售。旧账本仅在分类管理由用户主动补充，按稳定 ID 和同名项跳过已存在或已归档分类，不自动复活或覆盖；删除采用软归档 |
| 新账本种子账户 | 账户全局共享：新账本已有同币种（`baseCurrency`）的未归档账户时直接沿用，不再新建；没有时（如全新安装或首个 USD 账本）自动创建一个“现金”账户（0 初始余额），保证开箱即记 |
| 账户共享 | 账户（资产）为全局实体，所有账本共享；分类、商家、标签、预算、定时扣款、交易仍按账本隔离。账本只提供 `currency = baseCurrency` 的未归档账户（V1 不做汇率；仓库层校验交易两端账户与定时扣款账户的币种），归档为全局。余额 = 初始余额 + 全部账本中涉及该账户的未删除交易，由数据库按账户 / 类型 / 方向聚合；转账可记在任一账本，不计入任何账本收支。资产页显示全部账户：净资产与资产 / 负债只计当前账本本位币账户，其他币种单列“不计入净资产”，已归档单独分组。账户详情默认“全部账本”，可切换“仅当前账本”，其他账本的账单标出账本名，点击按账单所属账本打开编辑。最近使用账户跨账本有效（不在当前账本可用范围时回退到第一个可用账户） |
| 合并账户 | 账户详情 → 更多 →“合并到…”：目标须为同币种、未归档的其他账户（源可为已归档）。源账户的全部交易（所有账本、含回收站，作为账户或转入账户）与定时扣款改用目标；目标初始余额相加（溢出则报错）、初始时间取较早者；删除源账户；两者之间的转账合并后会成为自转账，连同其标签关联 / 执行记录一并删除（对合并后余额影响为零，确认框给出笔数）。单事务并持有 `RecurringDatabaseGate`；确认框列出影响数量、合并后的初始余额与时间、不可撤销，默认勾选“合并前先立即备份”（备份失败不合并）；最近使用账户为源账户时改为目标。纯规则在 `AccountRules`（JVM 测试） |
| 默认账本 | 名称"个人账本"、币种 CNY |
| 记账类型切换 | 切换支出/收入/转账时自动清空已选的分类 / 转入账户，防止脏数据 |
| 记一笔布局 | 顶栏为支出 / 收入 / 转账胶囊切换；语义色金额面板左侧显示当前分类圆标与名称，右侧大号等宽金额。横向分页一级分类网格（常规 5 列，窄屏 / 大字体 4 列，徽章约 42dp / 小屏 38dp），分类格无卡片底，选中以主色描边圆标 + 主色名称表示；分页用圆点与左右箭头。有子类一级切换到同区域二级网格，首格“直接记入”父类，独立返回仅改变视图不更改所选分类 ID；商家库按一级分类解析。账户、商家、标签和备注用紧凑 Material 3 底部面板。日期入口显示 YYYY-MM-DD，点击打开年 / 月 / 日三列滚轮（共享选中带、边缘渐隐、今天 / 昨天 / 前天快捷项会带动滚轮），不编辑时分并保留原本地时分。底部四行数字键盘常驻（常规约 52dp，矮屏 / 大字体 48dp），打开面板或系统输入法时不再收起，正文可用高度恒定，避免分类行数跳变造成的闪烁；保存键跨三行并提供强确认触感。转账保留双账户且无分类；旧账单原分类 ID 和已归档关联在明确改选前保留 |
| 安全锁超时 | 离开应用超过 30 秒后重新验证（文档只说"较长时间"） |
| 安全锁开启流程 | 开启前先做一次生物识别 / 设备凭据验证，成功才启用 |
| 安全锁负按钮 | "退出"直接关闭应用，不可绕过 |
| 交易校验 | 纯规则（金额 / 分类类型匹配 / 转账账户）在 `domain/calc/TransactionRules`，有 JVM 测试 |
| 触感反馈 | 中央“记一笔”使用系统 `EFFECT_CLICK`，账单长按使用增强短触感，最终删除确认使用公开 `EFFECT_DOUBLE_CLICK`；新增保存点击使用公开 `EFFECT_HEAVY_CLICK` 并安全降级；日期滚轮换值使用系统 `CLOCK_TICK` 轻刻度。取消 / 返回 / 外部 dismiss 无应用触感；所有反馈遵循系统触感开关 |
| 账单删除 | 首页长按账单 → 删除操作 → 二次确认。账单页长按进入多选：顶栏变为“已选 N 项 / 全选 / 删除”，可点日期头整日选择，删除一次确认后在单事务内移入回收站，并提供 Snackbar 撤销；返回键退出多选，选择随可见列表自动裁剪。回收站同样支持多选批量恢复 / 彻底删除，以及“清空回收站”（仅当前账本）。彻底删除在同一事务内删除标签关联与定时扣款执行记录（执行记录对应周期已被规则越过，不会重复生成；保留悬空记录会使备份恢复校验失败），批量操作按 500 个 ID 分批避开 SQLite 绑定参数上限 |
| 商家 / 分类删除 | 管理页移除归档 / 三点入口，长按进入重命名或删除菜单；删除采用软归档，保留历史账单与预算引用；一级分类删除同步停用二级分类 |
| 归档彻底删除 | 只对已归档项目开放（仓库层再次校验），每次在单事务内执行，涉及定时扣款时持有 `RecurringDatabaseGate`；确认框说明影响数量（含回收站）、不可撤销，并默认勾选“删除前先立即备份”（备份失败则不删除）。标签：删除标签与账单关联。商家：删除商家与分类关联，引用账单商家置空。分类：连同已归档子类一起删除，仍有使用中子类时禁止；有账单或定时扣款引用时必须选同账本、同类型、未归档的替代分类整体迁移；相关预算删除。账户：删除所有账本中涉及它的账单（含转账另一端，会影响对方余额）、执行记录与定时扣款规则，确认框说明账单分布的账本数。账本：仅已归档且非当前，需输入账本名确认，按恢复时的清表顺序删除全部数据，至少保留一个未归档账本；账户为全局共享不会删除，确认框说明余额会因此变化的账户数 |
| 记一笔新建分类 | 二级网格末尾“新建”格；无子类的一级分类长按 →“添加二级分类”。复用分类管理的 `CategoryIconSheet`（名称 + 可选图标），校验与报错来自 `CategoryRepository.addCategory`，创建后自动选中并展开 |
| 商家与分类 | 商家可关联多个一级分类；`2→3` 迁移从既有交易（含软删除历史）提取有效关联，保持同账本、同收支类型约束。新建商家时若同账本已有未删除的同名商家（忽略首尾 / 多余空白与大小写），复用该记录并补充分类关联，不再生成重复商家；记一笔商家列表同样按名称去重显示（同名组优先显示当前已选项），历史重复记录与其账单引用保持不变 |
| 分类图标库 | 分类管理新建分类时可在图标库（`CategoryIconLibrary`，按组展示）中选图标，或选“自动”；长按分类 →“更换图标”可随时修改或恢复自动。数据库只存稳定字符串 key，数据层仅校验为空或 ≤64 字符的非空字符串；未知 key 由 UI 回退为按名称匹配。默认种子与“补充常用分类”不设图标（自动） |
| 分类图标 | 41 个预置一级分类按语义映射 Material Vector，自定义名称按关键词和收支类型确定性映射，未知名称使用固定回退。圆标为扁平浅色调圆底 + 同色相高饱和图标，无阴影与渐变；色相取自 13 个彼此区分明显的精选色相，按分类 ID 稳定哈希，保留图标无障碍名称 |
| 订阅自动记账 | 本地订阅规则支持每日 / 每周 / 每月 / 每年，到期自动生成普通支出交易；WorkManager 最短 15 分钟周期按系统调度尽力执行，打开应用时补处理到期项目。执行标记、交易、下次时间在同一事务内，防重复；暂停期间不补记，恢复后从下一次到期继续。不会向商家或支付渠道发起真实扣款 |
| 备份位置 | `BackupStore` 抽象：默认目录在 Android 10+ 为 `Documents/LedgerBackups/`（MediaStore 写入，无需权限，卸载后保留；重装后旧文件不再归本应用所有，不出现在列表中，可经“从文件恢复”导入），Android 8–9 为应用专属外部目录（卸载即删除）。可改用 SAF 自定义文件夹（持久授权），或恢复默认。自定义文件夹授权丢失或不可写时自动与手动备份都回退到默认目录并记录警告（红字提示），不静默清除用户设置。自动备份无需先选目录。轮换（7 日 + 4 周 + 12 月）只处理严格命名的 `ledger-backup-*.json`，不动恢复前备份与其他文件。恢复前备份优先写入当前位置，不可用时写入 `filesDir/pre-restore-backups` |
| 备份管理 | 数据管理 → 备份管理：位置（默认 / 自定义）与更改、自动备份开关、立即备份（上次时间）、备份文件列表（时间 / 类型 / 大小，可恢复、另存为、删除）及应用内部的恢复前备份分组 |
| 应用语言 | 设置 → 语言：跟随系统 / 简体中文 / English。Android 13+ 由系统 `LocaleManager` 保存（`generateLocaleConfig`，系统“应用语言”中也可切换），8–12 存 SharedPreferences 并在 Application / Activity `attachBaseContext` 套用。中文为默认资源（`values/`），英文在 `values-en/`，字符串按区域拆分为 `strings_common / core / main / settings`。数据层错误用 `UserFacingException`（资源 ID），ViewModel 用 `UiText`，由 UI 按当前语言解析；日期用 `DateLabels`。用户数据（分类、账户等名称）不翻译；新建账本的预置分类与默认名称按创建时语言生成，种子 ID 仍由中文规范名派生以保持稳定；英文分类名也能匹配图标 |
| 备份兼容 | JSON 格式版本 5（账户不再写出 `ledgerId`），可读取旧版 1–4（缺省 `iconKey` 视为自动图标；旧账户的 `ledgerId` 只用于按与迁移 4→5 相同的规则把跨账本同名账户改为 `名称（账本名）`，恢复后均为全局账户；定时扣款只校验账户币种与账本一致）；包含订阅数据及商家分类关联，恢复时校验引用和版本；图标 key 仅用于显示，非法值不阻断恢复，回退为“自动”。SQLite 备份接受数据库版本 1–5，v4+ 另校验分类 `iconKey` 列，v5 另校验 `account` 表无 `ledgerId` 列；旧版本文件替换后由 Room 显式 Migration 升级 |
| 系统窗口留白 | 根 Scaffold 不重复处理系统栏；各页顶栏处理状态栏，tab 底栏处理手势区，非 tab 页由自身 Scaffold 处理底部安全区；导航内容消费已应用的 inset |

## 构建与工具链

| 项 | 决策 |
|---|---|
| JDK | 21（需完整 JDK，含 jlink） |
| Gradle | 8.13（wrapper 发行版地址为腾讯镜像，国内外均可访问） |
| Android SDK | platform 36 / build-tools 36.0.0 |
| 依赖仓库 | 阿里云镜像优先，其后回退 google() / mavenCentral() |
| KSP | `ksp.useKSP2=false`（KSP1 模式；KSP2 与当前 Room 组合存在 MissingType 兼容问题） |
| release 签名 | 暂用 debug keystore，便于直接安装；正式分发需独立 keystore |
| 本地脚本 | 根目录 `build.ps1` 为作者本机脚本，使用仓库外的自带工具链（`.tools/`、`.android-sdk/`，已被 git 忽略）；保存为 UTF-8 BOM，否则 Windows PowerShell 5.1 会误读中文注释 |

通用构建方式见 [README](../README.md#构建)。
